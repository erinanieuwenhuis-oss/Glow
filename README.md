# glōw — skin ritual tracker

Installable PWA (single-page app, no build step).

Live at: `https://<your-username>.github.io/<repo-name>/`

## Deploy
Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)`.

## Update
Edit files, commit, and bump `CACHE = 'glow-vN'` in `sw.js` so installed copies refresh.
